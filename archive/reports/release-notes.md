# minebot 1.0.3-beta.3

本次修复伙伴运行依赖中此前报告的 21 项中危告警（两个底层漏洞及其依赖链）：

- uuid 固定为官方修复版 11.1.1。
- minimatch 固定为官方修复版 11.0.1；升级 ESLint 至 10.14.0，移除不兼容的旧配置依赖。
- 语音组件构建工具原本只需要清理固定目录，却引入 rimraf 3 / glob 7；以项目内可审查的原生目录清理适配层替换这部分依赖，保留回调和同步接口，不支持通配符，也不改变 Opus 编解码功能。
- 建造代码校验内置 ESLint 配置，不再依赖用户目录里的配置文件。
- 新增兼容性回归测试；CI 将生产依赖审计门槛改为包含低危在内的全部级别。

生产依赖审计：桌面程序 0 项，伙伴运行时 0 项。该结果对应本次锁定版本和审计时的数据库，不代表不存在尚未公开的漏洞。

仍为测试版：受限生存建造、跨版本整合包兼容、公网双向语音等验收边界不变。无需正版账号登录，仍使用用户自己的 WorkBuddy 账号或模型 API。未自动覆盖本机安装或发布 GitHub Release。
