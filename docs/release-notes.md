# minebot 1.0.8 正式版

使用自己的整合包与世界，通过简体中文向导配置模型、准备服务器，并管理一个 AI 伙伴。

## 下载与使用

Windows x64 用户下载 **minebot-setup-1.0.8.exe**。无需下载源码，也无需另行安装 Node 或 Python。升级前正常停止服务器并关闭旧版，安装后左上角显示 `1.0.8`。

WorkBuddy 通道使用用户本机客户端的登录账号和积分；也支持用户自己的 OpenAI 兼容 API。选择自有游戏实例或整合包及世界后，按向导准备环境并开服。

## 本次更新

- 主配置器升级为黑白灰浅蓝的正式克制界面，统一细边框、圆角、层级与信息密度。
- 自检改为清晰的状态时间线，区分已通过、可自动准备、需要选择、等待后续与必须处理。
- 服务器准备和管家请求增加真实忙碌状态，完成或失败后自动停止活动提示。
- 去除装饰性渐变与大面积彩色状态块，主要操作使用深灰黑实体按钮。
- 动画遵循系统“减少动态效果”设置，补充键盘焦点和 980×680 验证，并提供高对比与强制颜色适配。
- WorkBuddy 临时超时、限流、网关错误或连接重置时自动有限重试。
- 检测模型流式回答中途断开或空响应，避免把残缺内容当作正常回答。
- WorkBuddy 登录凭证被拒绝时自动刷新一次，并区分登录失效、积分不足和请求频繁。
- 游戏内不再显示笼统的英文断线句，改为明确的简体中文提示。
- 日志记录脱敏后的错误类型和尝试次数，新增断流与凭证刷新回归测试。
- 每次安全停服后更新当天的 `服务器存档-日期`，并自动作为下一次服务器来源。
- 同一世界不再因重新选择每日存档而生成多余日期后缀，成功更新后清理旧回滚副本。
- 构建流程锁定并验证内置 Node.js 22，防止语音原生模块版本不匹配。

## 验证与范围

完整自动化回归通过；本次额外使用 Electron/Chromium 验证正常动画、减少动态效果、键盘焦点和最小窗口布局。WorkBuddy 恢复链路继续通过模拟 502、流式中断和 401 凭证失效验证，未额外消耗用户积分进行真实模型请求。安装包保持空白默认配置，不携带个人账号、存档、人设、地址或日志。

任意整合包兼容、复杂自动生存建造和跨客户端皮肤自动分发不属于已完成范围。外网联机和双向麦克风语音需按用户环境实测。内容模组冲突先展示影响，由用户选择；离线身份服务器仅应邀请信任的玩家。
