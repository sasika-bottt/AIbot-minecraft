# minebot 使用指南

[返回主页](../README.md) · [下载正式版](https://github.com/sasika-bottt/AIbot-minecraft/releases/latest)

## 安装与升级

下载 Release 中的 `minebot-setup-1.0.8.exe`，运行 Windows 安装向导。安装包已包含 Node 与伙伴组件，无需安装 Python。升级前正常停止服务器和伙伴，再关闭旧版应用。安装后左上角应显示 `1.0.8`。

安装包不附带个人设置。已有用户的本机配置与存档不会因为仓库纯净化而被清空。配置保存在 Windows 应用数据目录下的 `minebot-desktop/profile`；不要把该目录上传到问题反馈中。

## 1. AI 模型

- **WorkBuddy 积分通道**：在本机安装并登录 WorkBuddy，点击“检测账号”，读取可用模型并选择。使用自己的账号及积分，服务可用性取决于 WorkBuddy。
- **其他模型**：填写 OpenAI 兼容 API 地址、模型名称与自己的 API Key。Key 通过 Windows 系统加密保存。

## 2. 游戏与整合包

选择 PCL2 已安装实例、本地 ZIP / MRPACK / 7Z，或已解压目录；核对 Minecraft 版本、加载器和世界。也可指定已有专用服务端目录。软件会构建独立服务器副本，原世界不直接作为运行目录。

切换实例后需要重新选择世界。无法识别版本时，按整合包作者提供的信息选择，不能任意猜测。MRPACK 可下载清单中允许且可验证的资源，其他整合包格式的支持范围见 [兼容性说明](COMPATIBILITY.md)。

## 3. 可选语音与伙伴外观

语音默认关闭。启用后尝试添加匹配的 Simple Voice Chat 及必要依赖，可能向当前客户端的 mods 目录添加新文件；已在运行的游戏需要重启。其他玩家也需要安装兼容语音模组。

可以设置伙伴的游戏名称、人设、回复方式与皮肤。皮肤导出后，需要各玩家客户端支持并配置 CustomSkinLoader 才能显示；不会自动分发给所有玩家。

## 4. 联机与开服

完成自检，必要时点击“检查并自动准备资源”。软件会匹配 Java 并尝试下载缺失的兼容运行资源。进入监管中心启动服务器，等待状态变为可连接。

| 使用方式 | 地址与条件 |
| --- | --- |
| 同一台电脑游玩 | 通常为 `127.0.0.1:25565`，以界面实际端口为准 |
| 同一局域网 | 使用开服电脑的局域网 IP 和游戏端口，需允许防火墙连接 |
| 外网朋友加入 | 准备游戏 TCP 隧道，使用检测到或手动填写的公网地址 |
| 外网语音 | 另需 Simple Voice Chat 对应的 UDP 隧道，与游戏 TCP 地址区分 |

只开启隧道不代表服务器已启动。游戏服务器通过本机连接验证后，顶部才会显示可加入地址。服务器采用离线身份模式；管理员名单中的名称必须与玩家实际名称大小写一致，运行时授权前让该玩家先加入服务器。

## 5. 停服与恢复

在监管中心点击停止，等待世界保存和单人存档同步完成。若同步失败，可以点击“重新同步单人存档”；它会使用该次服务器原本对应的游戏目录。

异常停服后，软件会判断世界是否变化；必要时先创建备份，再校验恢复副本。校验失败时保留文件，由用户选择完好的世界。涉及内容模组的冲突会先展示影响，不自动删除模组或回退进度。

## 反馈问题

在 [Issues](https://github.com/sasika-bottt/AIbot-minecraft/issues) 中提供：应用版本、Minecraft / 加载器版本、触发步骤、错误文字，以及脱敏后的相关日志片段。请去掉 API Key、账号令牌、个人路径和公网地址。
