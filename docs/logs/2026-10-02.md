# 2026-10-02 · 生存模式 / 零 token 自治的硬结论 / 大型施工

## 一、bot 转生存模式
- `settings.js` 的 `base_profile` 由 `assistant` 改为 **`survival`**；`wb.json` 的 `modes.cheat` 置 **false**；服务端 `gamemode survival <bot>`。
- 生效后用脚本复现 mindcraft 的配置合并顺序（`_default.json` → `base_profile` → 具体 profile，后者覆盖前者）做**确定性校验**，确认 `base_profile=survival`、`cheat:false`、`hunting:false`、`idle_staring:true`。
- 效果：bot 不能飞、要吃饭、放置方块真消耗物品栏。
- 教训：**改 mode 默认值要改两处** —— `modes.js` 里的 `on` 只是初始默认，启动时会被 `wb.json` 的 `modes` 字段覆盖，两处都改才生效。

## 二、关于「低 token 自主活动」的硬结论
- mindcraft 里唯一能让 LLM 自主找活干的是 **`!goal`**（自提示循环），它已在 `actions.js` 里被**硬编码禁用**（unblockable，`blocked_actions` 也改不动）。实测 bot 尝试后回复「自主模式被锁了」。
- **真正零 token 的自主行为只有 `modes`** —— 纯代码、每 tick 跑、一次 API 都不调。`wb.json` 最终配置：自保 / 解卡 / 自卫 / 捡物 / 插火把 / 保持距离 / 张望 **开**；发呆 / 怕死 / 狩猎 / cheat **关**。
- 「LLM 级自主性」= 持续调 API 的自提示循环，与「token 极少」直接矛盾 → 取舍由使用者定。

## 三、两个必须记住的坑（已固化）

1. **`sendCommandFeedback` 绝不能开**（本轮最大事故）：临时打开后，**每条 RCON 指令的执行结果都会广播进聊天栏** → 被 mindcraft 当成玩家消息逐条喂给 bot → 疯狂烧 token，且 bot 开始"自主行动"乱动工地。**RCON 的返回值本就不受该 gamerule 影响**（`execute if block` 照样返回 Test passed / failed），所以排查时也**不需要**开。`commandBlockOutput` / `logAdminCommands` 同理全程保持 false。
2. **悬挂实体（`item_frame` / `painting`）坐标 = 支撑方块坐标 + 1 + 0.03125**（朝 +x / +z 方向；朝 -x / -z 则 −0.03125）。少加 1 会把实体塞进墙里 → 服务端判「支撑无效」→ **约 5 秒后自行销毁，不掉落、不留痕**，极难排查。`item_frame` 用大写 `Facing`（0下 / 1上 / 2北 / 3南 / 4西 / 5东）；`painting` 用小写 `facing`（0南 / 1西 / 2北 / 3东）。

## 四、大型施工（RCON 批量建造）
大型工程一律用 RCON `/fill` + `setblock` 直接建（秒完成、可验收、零 token），**不交给 bot 的 LLM 循环**：
- 交通干线「西海大道」约 182 格：穿山脊用 52 格隧道，出洞 59 格缓坡 + 溪桥 + 低地堤道，直抵西岸码头；37 个断面贯通性验收 0 异常。
- 湖畔居所（两层 + 屋顶露台 + 湖景阳台 + 菜园），20 项定点验收全过。
- 码头完善：灯塔（带爬梯 + 海晶灯室）、起重机、系缆桩、晾鱼架、防波堤、路灯。

**可复用规矩**：
- 远距离施工前先 `forceload add`，否则报「position is not loaded」；完工 `forceload remove all`。
- **验收先 `save-all flush`，再直读区块存档**（比逐格 RCON 试探准且快）。
- 实体数量用**计分板实时统计**为准（静态读存档有边界重复问题）。

## 五、bot 能力边界（实测）
- 大型工程由外部 RCON 建；bot 只做小活儿（`!placeBlock`、`!newAction` 写代码逐块放）。
- `construction_tasks.js` 里的蓝图批量建造命令**未接通**（调用处已注释），`!checkBlueprint` / `!getBlueprint` 在 `blocked_actions` 里被禁 → **别指望 bot 自己盖房**。
- `!newAction` 已解锁（`allow_insecure_coding=true`、`code_timeout_mins=-1`）；`!goal` 在 `actions.js` 里硬禁用。
