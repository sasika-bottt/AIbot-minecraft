## STT 阶段打通：语音双工完成
- 安装 faster-whisper 1.2.1（清华源）+ `av` **必须降到 14.2.0**（19.0 移除了 `metadata_errors` 参数，导致转写报错）。
- 模型下载：`HF_HUB_DISABLE_XET=1` 必须（hf-mirror 不支持 Xet 存储，会 401）；`small` 模型缓存在 `mindcraft/whisper_models/`。

- 新增 `stt_server.py`：常驻 Python 进程，stdin/stdout JSON 行协议，模型只加载一次。
- `voice.js` 扩展：`voicechat_player_sound` 按 sender 累积 PCM + RMS 门限 400 + 静音切片 → ffmpeg 转 16k wav → whisper → `agent.handleMessage`。
- 端到端测试通过：TTS 合成语音 → whisper 识别 → 文字正确（除个别同音字）。
- 使用方式：按 `V` 说话，停顿后 bot 理解并语音 + 文字回复。
