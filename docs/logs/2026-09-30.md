# 2026-09-30 · 整合包 AI 伙伴 + 语音（调研完成，待实施）

## 需求
在 1.20.1 Forge 整合包里加入 AI 伙伴，并实现**全套游戏内语音**（TTS 说 + STT 听）。

## 调研结论（GitHub-first）

- **FML3 握手**：Forge 1.20.x 需要 FML3 握手，官方 npm 包只到 FML1；**Mykola1453/node-minecraft-protocol-forge 默认分支已含 `forgeHandshake3.js`**（PR#28 的代码，作者用 Mekanism / BOP 实测连通）→ 定点采用。
- **必须用专用服务端**：PR 作者明确 **单人开局域网带 mod 会反序列化报错，专用服务器正常** → 不走 LAN，改装独立 Forge 服务端（复用整合包 mods）。
- **语音选型**：
  - Simple Voice Chat mod（Forge 版存在）—— 游戏内 3D 语音通道
  - `mineflayer-simplevoice`（npm 1.1.1）—— bot 端收发 SVC 语音
  - `edge-tts` —— 免费中文 TTS（后因 JS 包被微软 DRM 挡死，改走 Python CLI，见 10-01 日志）
  - faster-whisper —— 本地语音识别（显卡占用是已知风险，选择接受）

## MVP 路线
独立 Forge 服务端（复用整合包 mods）→ FML3 握手进服 → SVC + edge-tts + whisper 语音链。
