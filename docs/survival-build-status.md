# 生存建造开发状态

生存施工执行器已接入管家窗口和已有游戏伙伴，界面明确标为受限试用。它尚未达到通用的全自动生存建造，不应标记为功能完全完成。

当前测试覆盖指定坐标的简单方块采集、拾取、部分原木到木板的合成和逐块放置，以及已加载目标的障碍检查、低血量保护、暂停和依据实际世界状态重新核对。执行器不接受直接拆除施工区障碍的计划；采集位置必须显式列出且不能与施工范围重叠。

已做过的真实游戏测试使用临时服务器副本、测试伙伴和预先布置的小型材料及方块。它不能证明任意建筑、全部模组或玩家世界都能完成。

当前可由对话生成可编辑预览，用户确认后备份、启动，并将计划保存到本机；继续时核对服务器工作目录及实际游戏世界标识并重新备份。仍需更严密的世界身份绑定与重启测试，并支持更多材料、配方、工具制作和耐久、障碍处理、复杂建筑及更大规模真实服务器测试。不得把受限试用表述成已完成的全自动生存建造。

`npm run test:survival-build` 运行模拟测试；`tests/live-survival-build.cjs` 是显式传入测试配置才运行的隔离服务器试验，测试脚本不会将服务器副本导出回玩家存档。
