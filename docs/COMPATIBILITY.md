# 支持范围与实验功能

## 正式版 1.0.7 的定位

正式版提供模型配置、整合包导入、服务器环境准备、伙伴运行与存档管理。游戏与模组的兼容性仍受版本、加载器、协议和第三方组件影响，不保证任意整合包都能运行。

| 功能 | 当前范围 |
| --- | --- |
| 平台 | Windows x64；运行时内置 Node，无需 Python |
| 模型 | WorkBuddy 本机登录积分通道；用户自备 OpenAI 兼容 API |
| 服务端准备 | 原版、Fabric、Forge、NeoForge，依赖官方可用资源 |
| 整合包 | 本地目录 / ZIP / 7Z；MRPACK 清单中受支持的资源下载；CurseForge 清单和任意第三方下载器不能保证自动处理 |
| Java | 优先匹配本机环境，缺少时尝试从官方来源安装到应用数据目录 |
| 模组依赖 | Fabric 按文件哈希确认项目及版本后补齐；Forge / NeoForge 的复杂依赖由加载器继续验证 |
| 语音 | Simple Voice Chat、Windows 语音组件；声音及识别能力依赖用户系统。外网需额外 UDP 映射 |
| 皮肤 | 导入、生成与导出；客户端显示取决于 CustomSkinLoader 等配置，跨客户端自动分发未实现 |
| 世界恢复 | 原副本保留；备份及可识别 NBT / 区块校验；无法安全验证时等待用户选择 |

## 本版验证依据

21 组自动化回归覆盖配置、导入、服务器准备与退出、WorkBuddy 组件、伙伴管理、依赖缓存、存档恢复、界面状态及建造安全。

2026-11-14 的真实隔离测试验证了 Minecraft **1.21.11 + Fabric 0.20.1** 下的服务器启动、伙伴进服、语音 UDP 连接、管理员授权/撤权和正常停服。2026-11-16 复核了该版本构建产物的代码一致性与纯净配置。公网隧道、麦克风双向交互及其他整合包不在这轮完整验收范围内。

## 管家建造的范围

生存建造仍属于受限功能：支持指定采集点、部分普通方块与原木合成木板、逐块施工、暂停与重新核对；施工前备份。复杂配方、工具制作、任意规模建筑和全部模组材料尚未完成。

管理员建造允许在确认方案与范围后执行受控命令，跳过材料收集。命令被提交不等于每一个方块均已生成，仍需检查执行结果。

## 身份与外部服务

构建的服务器副本使用 `online-mode=false` 和 `enforce-secure-profile=false`。正版和离线玩家均可连接，但名称不证明账号归属；只应邀请、授权信任的玩家。

WorkBuddy、模型 API、GitHub 下载、Modrinth 和穿透服务的可用性、额度及费用由对应服务决定。应用提供可安全执行的准备与恢复，不会自动绕过模组协议限制或删除世界内容来强行开服。
